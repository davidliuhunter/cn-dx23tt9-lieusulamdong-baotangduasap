# Tài liệu Đồ án (Thesis)

Thư mục này chứa tất cả các tài liệu văn bản liên quan đến đồ án.

---

## Cấu trúc tài liệu

```
thesis/
├── PROPOSAL.md               # Đề xuất đồ án (ban đầu)
├── FINAL-REPORT.md          # Báo cáo cuối cùng
├── TECHNICAL-DESIGN.md      # Thiết kế kỹ thuật
├── USER-MANUAL.md           # Hướng dẫn sử dụng
├── API-DOCUMENTATION.md     # Tài liệu API
└── ARCHITECTURE.md          # Kiến trúc hệ thống
```

---

## Các tài liệu bắt buộc

### 1. PROPOSAL.md
- Mục đích, mục tiêu đồ án
- Phạm vi công việc
- Timeline dự kiến
- Công nghệ sử dụng

### 2. FINAL-REPORT.md
- Tóm tắt công việc hoàn thành
- Kết quả đạt được
- Lessons learned
- Kết luận & kiến nghị

### 3. TECHNICAL-DESIGN.md
- Kiến trúc hệ thống
- Database schema
- API endpoints
- Quy trình xử lý

### 4. USER-MANUAL.md
- Hướng dẫn sử dụng cho người dùng cuối
- Các tính năng chính
- Hướng dẫn công cộng & admin
- FAQs

---

## Lưu ý khi soạn tài liệu

1. **Viết rõ ràng, ngắn gọn** - Dễ đọc, dễ hiểu
2. **Bao gồm sơ đồ/hình ảnh** - Hỗ trợ trực quan
3. **Update liên tục** - Khi thay đổi tính năng
4. **Lưu định dạng** - PDF hoặc Markdown
5. **Bản tiếng Việt** - Tuân thủ yêu cầu đồ án

---

## Template & Hướng dẫn

Xem các file trong thư mục này để có hướng dẫn chi tiết.

---

## Nộp tài liệu

Trước ngày báo cáo, đảm bảo:
- [ ] Tất cả file tài liệu đã hoàn thành
- [ ] Lưu dưới dạng PDF hoặc định dạng được chấp nhận
- [ ] Nộp thư mục `thesis/` đầy đủ trong repository
- [ ] Có file README.md hướng dẫn
